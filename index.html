Bab 6: Analisis Data (Materi Pembelajaran & E-LKPD Interaktif)

1. Mengenal Data & Satuan Ukuran Data

Data berasal dari kata datum yang berarti fakta atau keterangan nyata. Data bisa berupa teks, angka, gambar, suara, maupun video.

Jenis-Jenis Data:

  • Data Kualitatif (Kategorikal): Data yang berbentuk deskripsi, sifat, atau kategori (tidak berupa angka). Contoh: Hobi siswa, warna favorit, jenis kelamin.
  • Data Kuantitatif (Numerik): Data yang berbentuk angka hasil pengukuran atau perhitungan. Contoh: Tinggi badan, berat badan, nilai ulangan.

Satuan Ukuran Data Digital:

Satuan Simbol Kapasitas
Byte B 8 bit (1 karakter huruf)
Kilobyte KB 1.024 Byte
Megabyte MB 1.024 KB
Gigabyte GB 1.024 MB
Terabyte TB 1.024 GB

2. Perkakas Pengolah Lembar Kerja (Spreadsheet)

Untuk mengolah data dalam jumlah banyak, kita menggunakan aplikasi pengolah lembar kerja seperti Microsoft Excel, Google Sheets, atau LibreOffice Calc.

  • Workbook: File buku kerja secara keseluruhan.
  • Worksheet: Lembar kerja di dalam workbook (berupa tabel).
  • Column (Kolom): Bagian yang memanjang ke bawah, ditandai dengan huruf (A, B, C, ...).
  • Row (Baris): Bagian yang melintang ke samping, ditandai dengan angka (1, 2, 3, ...).
  • Cell (Sel): Pertemuan antara kolom dan baris (contoh: B3 artinya Kolom B, Baris 3).
  • Range (Rentang): Kumpulan dari beberapa sel yang dipilih (contoh: A1:C5).
💡 Tips Tampilan: Gunakan fitur Freeze Panes untuk membekukan baris judul tabel agar tidak ikut bergeser saat layar digulir (scroll) ke bawah.

3. Pengolahan Data Dasar (Rumus & Fungsi)

Setiap penulisan rumus di Excel/Spreadsheet wajib diawali dengan tanda sama dengan (=).

Fungsi / Rumus Kegunaan Contoh Penulisan
SUM Menjumlahkan seluruh angka dalam rentang sel =SUM(B2:B10)
AVERAGE Menghitung nilai rata-rata =AVERAGE(B2:B10)
MAX Mencari nilai paling tinggi / terbesar =MAX(B2:B10)
MIN Mencari nilai paling rendah / terkecil =MIN(B2:B10)
COUNT Menghitung banyaknya sel yang berisi angka =COUNT(B2:B10)
IF Menguji kondisi logika (Benar / Salah) =IF(B2>=75;"Tuntas";"Remedial")

4. Pengolahan Data Lanjutan & Visualisasi

  • Sort (Mengurutkan Data): Menyusun data secara berurutan, baik dari terkecil ke terbesar (Ascending / A-Z) maupun terbesar ke terkecil (Descending / Z-A).
  • Filter (Menyaring Data): Menampilkan data tertentu saja sesuai kriteria yang diinginkan dan menyembunyikan sisanya sementara.
  • Visualisasi Data (Chart): Mengubah tabel angka menjadi grafik agar mudah dibaca:
    • Column/Bar Chart: Membandingkan jumlah antar kategori.
    • Line Chart: Melihat tren atau perubahan data dari waktu ke waktu.
    • Pie Chart: Melihat persentase bagian dari keseluruhan data.
